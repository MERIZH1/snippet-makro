# Snippet-Makro

Installierbare Offline-Web-App für persönliche Textbausteine.

Die veröffentlichte App enthält keine Textbausteine, Serveradressen oder Zugangsdaten. Persönliche Inhalte werden ausschließlich im lokalen Browserspeicher des jeweiligen Geräts abgelegt. Die App sendet keine Nutzerdaten an externe Dienste.
