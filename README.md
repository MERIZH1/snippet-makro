# Snippet-Makro

Installierbare Offline-Web-App für persönliche Textbausteine, kopierbare Memos und ein lokales Telefonbuch. Die Oberfläche startet auf Englisch und kann bei Bedarf mit der integrierten Seitenübersetzung von Edge übersetzt werden. In unterstützten Edge-Versionen kann eine kompakte Kopieransicht mit Ordnern als dauerhaft sichtbares Schwebefenster geöffnet werden. Makros lassen sich außerdem mit der integrierten Übersetzungsfunktion von Edge und Chrome direkt auf dem Gerät übersetzen.

Die öffentliche Startseite dient nur zur Installation. Die eigentliche Oberfläche wird im normalen Browser nicht geöffnet. Die Oberfläche startet auf Englisch; für eine andere Menüsprache kann die Seitenübersetzung von Edge verwendet werden. In den Einstellungen lassen sich die Ausgangssprache und Datensicherungen verwalten. Die Ausgangssprache wird standardmäßig automatisch erkannt; bei kurzen Texten ohne sichere Erkennung muss sie manuell gewählt werden.

Im Makro-Editor können Hyperlinks auch direkt aus einer E-Mail oder Webseite eingefügt werden: Beim Einfügen mit Strg+V bleiben die verlinkten Wörter klickbar.

Die veröffentlichte App enthält keine Textbausteine, Kontakte, Serveradressen oder Zugangsdaten. Persönliche Inhalte werden ausschließlich im lokalen Browserspeicher des jeweiligen Geräts abgelegt. Bei der Übersetzung wird der Makrotext lokal im Browser verarbeitet und nicht an einen Übersetzungsdienst gesendet. Edge/Chrome müssen das Sprachmodell für die gewählte Sprache zunächst einmalig herunterladen; danach funktioniert die Übersetzung ohne Internetverbindung. Memos werden nie übersetzt. Eingefügte Hyperlinks werden beim Kopieren als klickbare Links übertragen, sofern das Zielprogramm HTML-Zwischenablage unterstützt.
